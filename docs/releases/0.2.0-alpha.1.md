AgentHarbor 首个可操作桌面版本：以纯黑助手会议界面管理本地 Git 项目，让 Codex 与 Claude Code 接力执行、运行检查、独立审核，并在限定轮数内自动返工。

包含项目选择、会议创建、助手发现、任务暂停/继续、消息与小型文本附件、代码改动、测试证据、审核记录和重启恢复。

验证：14 项运行时测试；三平台原生 Electron 夹具测试与 ZIP 打包；macOS 真实 Codex → 主机测试 → Claude Code 的桌面闭环。具体 CI 结果见本仓库 Actions。

使用前需要 Git 及已认证的 Codex、Claude Code CLI。ZIP 未签名、公证，图标暂为 Electron 默认。Windows `.cmd` 助手启动器尚未适配；Windows/Linux 真实模型访问仍待验证。自由多助手讨论、@路由、自动任务拆解、OpenCode 执行与 Jev 后续实现。首次启动为空，README 截图使用标注的示例数据。

改动保留在独立 worktree；不自动提交、推送或合并。详细步骤与限制见 README 和 docs/desktop-alpha.md。
