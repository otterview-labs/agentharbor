简化创建任务：选择文件夹、在主输入框描述目标，点击“开始任务”即可创建并执行。也可以先输入目标，开始时再选择文件夹。

- “新建任务”直接进入目标输入区，不再强制填写表单。
- 默认以目标本身作为验收要求，沿用项目检查入口，Codex 执行、Claude Code 独立审核；完成仍需真实检查和结构化独立审核。
- 自定义验收、助手分工和检查命令收进“任务设置 → 高级设置（选填）”。新建时收起空任务详情栏。
- 取消文件夹选择保留目标；启动失败保留已创建任务并提供重试，避免重复创建。
- 保留普通文件夹支持与无固定文件数量/大小上限。

验证覆盖 26 项运行时测试、5 项原生桌面场景，以及桌面/窄窗口布局。没有测试入口的文件夹仍需按任务设置实际检查，默认检查不等同于拥有回归测试。既有 Windows 助手启动器、模型认证和未签名分发等 Alpha 限制不变。
