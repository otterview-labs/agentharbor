修复添加普通文件夹时错误要求 Git 仓库的问题。

- 普通文件夹不需要 Git 安装或初始化；任务在独立副本中执行，原目录保持不变。
- Git 项目继续使用 worktree；兼容已有项目与任务记录。
- 普通文件夹支持文件指纹、真实验证、独立审核、自动返工，以及新增/修改/删除列表。
- 主入口调整为“新建任务”，选择器和帮助文案说明两种目录类型。完整的新版紧凑布局仍是设计提案，此版本只调整入口与提示文案。
- 本机 22 项运行时测试、3 项原生桌面测试通过；真实 Codex → 检查 → Claude Code 的非 Git 文件夹闭环通过。三平台本提交 CI 记录见发布链接。

完成后从“改动与测试 → 打开工作区”查看或取回结果，不会自动覆盖原目录。普通文件夹排除依赖、缓存和构建目录，不解析自定义 .gitignore；限制 10000 个文件、256 MiB 总量、64 MiB 单文件，暂不支持符号链接与特殊文件。详见 README。

仍为未签名的 Alpha。Windows `.cmd` 助手适配、Windows/Linux 真实模型访问等既有限制不变。
