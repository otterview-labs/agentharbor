取消普通文件夹任务副本的文件数量、目录条目数、单文件大小和总大小限制。

- 不再因超过 10000 个文件、20000 个条目、64 MiB 单文件或 256 MiB 总量拒绝创建任务。
- 目录遍历与文件内容校验按流处理；支持时使用写时复制，不支持则正常复制。
- 流式遍历的文件指纹使用稳定顺序，避免不同 Unicode 文件名排序造成误判。
- 保留文件变化检测、独立副本、真实验证和独立审核。
- 依赖/缓存/构建目录默认排除规则，以及符号链接/特殊文件的既有限制保持不变。

本机回归覆盖 257 MiB 以上文件的完整复制、尾部字节变化识别与原文件保留，并补测超过 20000 个文件的真实任务副本创建。三平台测试和打包记录见发布页面。
